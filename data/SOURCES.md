# Sources of the corpus

The texts in `data/raw/` were collected in 2025–2026 for a non-commercial university course project (a retrieval-augmented question-answering assistant about Popping and funk-style street dance). `data/processed/` holds the cleaned plain text of the same 42 files, one `.txt` per raw file with the same name, so every row below covers both copies.

- Copyright in each text stays with its original author and publisher. The texts are kept here only so that the experiments in this repository can be reproduced; they are not offered for reuse.
- Wikipedia text is available under the [Creative Commons Attribution-ShareAlike 4.0 International licence (CC BY-SA 4.0)](https://creativecommons.org/licenses/by-sa/4.0/); the authors are the Wikipedia contributors listed in each article's page history. The clips were saved from the article pages as Markdown.
- The five owner notes are the repository author's own work.
- If you hold the rights to a text here and want it removed, please open an issue on this repository and it will be taken down.

The web clips do not record the address they were saved from. The URLs below were found afterwards by matching each clip's title and opening sentences against the live page (or, where noted, an archived copy). "Not confirmed" means no page with the same text could be found; no URL has been guessed. "No open licence identified" means the page states no licence that permits redistribution, so normal copyright applies.
